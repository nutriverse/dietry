# Get Food Consumption Score (FCS) colours

Get Food Consumption Score (FCS) colours

## Usage

``` r
fcs_get_colours()
```

## Value

A named character vector of recommended FCS classification colours

## Author

Ernest Guevarra

## Examples

``` r
fcs_get_colours()
#> acceptable borderline       poor 
#>  "#ECE1B1"  "#E67536"  "#D70000" 
```
